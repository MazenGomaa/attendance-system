كيفية تفعيل الموقع — How to enable location

آيفون (iPhone / Safari):
  • الإعدادات ← الخصوصية ← خدمات الموقع: تأكد أنها مفعّلة.
  • اضغط «ﺍA» في شريط العنوان ← إعدادات موقع الويب ← اسمح بالموقع.
أندرويد (Android / Chrome):
  • فعّل زر الموقع (GPS) من شريط الإشعارات بالأعلى.
  • اضغط أيقونة القفل 🔒 بجانب الرابط ← الأذونات ← اسمح بالموقع.
